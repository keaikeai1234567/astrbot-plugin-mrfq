# 每日发情

每日发情插件，作者 shutiaomao。

## 功能

- 🎯 每日发情，随机积分奖励
- 🔥 连续发情加成，越签越多
- 🏆 积分排行榜
- 📋 个人发情信息查询
- 📖 发情帮助
- 💖 发情成功自动给用户主页点赞 + 戳一戳

## 指令

| 指令 | 说明 |
|------|------|
| /发情 | 每日发情，领取随机积分，自动点赞+戳一戳 |
| /我的发情 | 查看个人发情统计 |
| /发情排行 | 查看群内积分排行榜 |
| /发情帮助 | 显示帮助信息 |

## 配置项

在插件配置面板中可调整：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 基础奖励最小值 | 10 | 每次发情最少获得的积分 |
| 基础奖励最大值 | 100 | 每次发情最多获得的积分 |
| 连续发情加成 | true | 是否启用连续发情额外奖励 |
| 连续发情加成上限 | 30 | 加成计算的最大天数 |
| 排行榜显示数量 | 10 | 排行榜显示前多少名 |
| 仅群聊可用 | true | 是否限制仅在群聊中使用 |
| 启用点赞与戳一戳 | true | 发情成功时给用户主页点赞并戳一戳（仅 OneBot 协议有效） |
| 点赞次数 | 10 | 每次发情给用户点赞的数量（QQ 每天对同一好友上限 10） |

## 奖励机制

- 每次发情获得 `基础奖励最小值 ~ 基础奖励最大值` 之间的随机积分
- 连续发情加成：每连续 1 天额外 +2 积分，上限为 `连续发情加成上限` 天
- 连续发情中断后重新从 1 天开始计算

## 点赞与戳一戳

发情成功后，插件会自动执行以下操作：

- 调用 `send_like` 给用户主页点赞，次数由「点赞次数」配置
- 调用 `group_poke`（群聊）或 `friend_poke`（私聊）向用户发送戳一戳
- 回复消息末尾追加「💖 今日已发情并给你{点赞次数}个赞~」

注意：
- QQ 每天对同一好友最多点赞 10 次，超过将被服务端忽略
- 点赞 / 戳一戳失败不会影响发情本身，仅记录日志
- 非 OneBot 平台将自动跳过，回复中也不追加点赞文案

## 数据存储

使用 SQLite 数据库，数据文件存储在插件数据目录下 `daily_sign.db`。

- `sign_log` 表：每次发情记录
- `user_stats` 表：用户汇总统计

## 安装

将本文件夹放入 `~/AstrBot/data/plugins/` 目录，然后在 AstrBot 后台重载插件即可。
